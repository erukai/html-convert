### Markdown Elements

- text:
    - heading (#)
    - paragraph

- styles:
    - bold (**) ///
    - italic (* / _) //
    - strikethrough (~~)
    - code (`)
    - code block (```)
    - block quote (>)
    - link ([]())
    - subscript (~)
    - superscript (^)

- list:
    - ordered list (1.)
    - unordered list (-)

- non-text:
    - horizontal rule (---)
    - line break (empty line) -> just use `<br>`
