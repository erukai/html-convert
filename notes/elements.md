### Markdown Elements

- text:
    - header
    - paragraph

- styles:
    - bold
    - italic
    - strikethrough
    - code
    - code block
    - block quote
    - link
    - subscript
    - superscript

- list:
    - ordered list
    - unordered list

- non-text:
    - horizontal rule
    - line break (empty line) -> just use `<br>`
